## 2. Induction (M1)

Twelve undirected runs were executed to find a seed. Three were seed-eligible;
`16f2` was used.

**The sign-off gate rejected the first candidate, and this is worth recording.**
Run `b07a` passed eligibility — goal attained, every event applied — but the
agent had called `report` at seq 6 and *then* made a further move. The contract
induced from it did not accept it:

```
STRUCTURAL | one of: move_ac | 'report' occurred (not offered here)
STRUCTURAL | cell 'report' required by artefact | run ended before it occurred
contract does not accept its own seed — NOT written
```

Nothing was written. The eligibility predicate in `induce.py` checks that the
goal is attained and that no event was blocked; it does **not** check that the
run *ends* with `report`. The self-verification gate caught what eligibility
missed, which is the safety net behaving correctly — but the gap is real and
cheap to close.

Induced term (Option 1 — the contract is a recording):


## 3. Undirected and enforced (3 disks)

| Arm | n | Conform | Applied moves (min/mean/max) | Blocked by world | Interventions |

| enforced | 10 | **10/10** | 7 / 7.0 / 7 | 0 | 74 |

Every run in both arms reached `-|-|321` — **the task outcome was attained
100% of the time in both arms.** What separates them is entirely the process:
the undirected agent took up to 21 moves for a 7-move puzzle and had 62 moves
refused by the world, while every enforced run executed exactly the recorded
seven.

Enforced interventions by kind: `STRUCTURAL` 49, `UNCLASSIFIED` 25. The
`UNCLASSIFIED` refusals are fail-closed rejections of requests outside the
vocabulary — naming a disk that is not on top of its peg.

Undirected failure classes: `STRUCTURAL` (all 10 failing runs), `UNMEDIATED`
(9), `GUARD_PRE` (5).

**Read the enforced 10/10 correctly.** With a straight-line contract the gate
permits exactly one action at each point, so conformance is guaranteed by
construction and is not itself a finding. The number carrying information is
**74 interventions across 10 runs** — how often the agent tried to leave the
recorded path and was stopped. Two runs needed none; one needed 21.

## 4. Failure cases

Each case starts from the conforming seed and applies one targeted change, so
the finding is attributable to that change alone. Both families are covered,
plus a HOLD control that must *not* fail.

| Case | Family | Expected | Verdict | Classes raised |
|---|---|---|---|---|
| structural | PROCESS | `STRUCTURAL` | violations | `COMPLETENESS`, `STRUCTURAL` |
| guard_pre | PROCESS | `GUARD_PRE` | violations | `GUARD_PRE` |
| guard_post | PROCESS | `GUARD_POST` | violations | `GUARD_POST` |
| completeness | PROCESS | `COMPLETENESS` | violations | `COMPLETENESS` |
| continuity | INTEGRITY | `CONTINUITY` | violations | `CONTINUITY` |
| schema | INTEGRITY | `SCHEMA` | violations | `GUARD_POST`, `SCHEMA` |
| ledger_mismatch | INTEGRITY | `LEDGER_MISMATCH` | violations | `LEDGER_MISMATCH` |
| unmediated | INTEGRITY | `UNMEDIATED` | violations | `UNMEDIATED` |
| hold_control | — | conforms | **conforms** | — |

**9/9 as expected.** Baseline (unmutated seed) conforms, so every rejection is
caused by the mutation and not by the harness.

Two of these needed a second attempt, and the reasons are informative:

**`COMPLETENESS` is harder to provoke than it looks.** Deleting the final
`report` does *not* raise it — by that point the exit guard already holds, so
the alignment simply deletes the missing cell, still terminates, and reports
`STRUCTURAL`. `COMPLETENESS` is raised only when **no** alignment reaches
termination with the exit guard satisfied. The case therefore truncates the run
to four events, before `solved` is ever established.

**The structural case is built by execution, not by editing.** Transposing two
events in the seed also breaks the state chain and the ledger, so it raised
`CONTINUITY` and `LEDGER_MISMATCH` alongside `STRUCTURAL` and the finding was
not attributable. It now drives `world.py` down a genuinely different legal
13-move solve, giving an internally consistent trace whose only fault is being
the wrong path. It raises `COMPLETENESS` as well, correctly: a 13-move
divergent path cannot align to a 7-cell recording *and* terminate.

`schema` also raises `GUARD_POST`, which is expected — a string in a boolean
field is both a typing fault and a frame violation.

## 7. Open items

- `induce.py` eligibility does not require the run to **end** with `report`; the
  self-verification gate catches the consequence, but the check is worth
  tightening so a seed is not wasted.
- `COMPLETENESS` is unreachable by removing the terminating cell alone for this
  contract shape. Not a defect, but it is a property of straight-line recordings
  worth stating rather than discovering twice.
- The directed renderer remains unwired, as `FREEZE_NOTES.md` records. Not
  needed while Hanoi is a semantics check rather than a three-arm evaluation.
- `artefact/` here is a copy; the semantic fixes must still be applied to the
  authoritative WebArena engine copy before claiming identical implementations
  across both tasks.
